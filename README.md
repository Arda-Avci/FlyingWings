# Flying Wings (playable demo)

An Asphalt-style arcade racer with flying sections. This repository only contains the built web demo for GitHub Pages;
the game source lives in a private repository.

Play: https://arda-avci.github.io/FlyingWings/

Controls: W/S throttle and brake, A/D steer, Space drift, N nitro. Double-tap and hold W (or Up) inside a flight zone to fly.
URL options: `?q=ultra|high|medium|low` (quality), `?car=S1|S2|S3|SS`.
